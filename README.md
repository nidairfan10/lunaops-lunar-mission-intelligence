# LunaOps — Lunar Mission Intelligence

## Overview
LunaOps is a developing educational prototype designed to explore lunar south-pole candidate regions using NASA lunar data.

## Project Goals
- Explore lunar terrain information.
- Compare selected candidate regions.
- Present scientific information through clear visualizations.
- Explain data sources, assumptions, and uncertainties.

## Planned Features
- Lunar terrain explorer.
- Terrain and slope analysis.
- Candidate-site comparison.
- NASA data source documentation.
- Mission analysis summaries.

## Planned Technologies
- React and JavaScript
- HTML and CSS
- Vite
- Interactive mapping tools, evaluated for lunar data
- NASA lunar datasets, including LOLA products

## Data Sources
- NASA Planetary Geodesy Data Archive: https://pgda.gsfc.nasa.gov/data/LOLA_5mpp/
- NASA Lunar Reconnaissance Orbiter data products: https://science.nasa.gov/mission/lro/data-products/

## Current Status
Planning and visual-prototype stage. Features and data integrations will be updated as they are implemented and tested.

## Limitations
LunaOps is an educational prototype, not an official NASA tool or a landing-site safety certification system.
